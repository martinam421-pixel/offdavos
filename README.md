# OFF DAVOS

Independent live info for WEF week in Davos.
We don't explain WEF. We explain Davos while WEF is happening to it.

- `index.html`, `css/`, `js/`: the site
- `data/updates.json`: Live "What changed today" feed
- `data/places.json`: Map entries

Deployed on Netlify from the `main` branch. No build step.
